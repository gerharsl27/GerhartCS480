CS 480 • Homework 3

HW 3: Your First XR Experience

My Unity Scene

Environment

My environment is based off the game "Trees hate you" where trees actively attack the user. While I don't have the experience yet to be able to make animations for the trees, I still wanted to include a similar vibe of the trees toying with the user. The user travels through a maze with the goal of escaping, encountering trees and their tricks along the way. In order, we see the tree blocking the path and causing a startling noise while saying "no," a shrub that tricks the user down a path to then jump in the way, a tree hiding around the corner and then shuffling away, and lastly the tree that gives a false sense of freedom only to hit the user with a truck. This ending was directly inspired by the ending of the real game's demo where the user is similarly hit by a truck. I really don't know why I chose to do this for my XR experience, it was just the only thing in my head when I was planning.

Key Takeaways

This homework gave a lot more creative freedom than the previous two, and also left a lot more for us to figure out on our own. Some things I have taken away from this is if I want a user to do something specifically I need to give them no other choice. So for my project, technically the user could avoid the first and second triggers if careful, however, I wanted to enforce the ending and some nefarious tree behavior, so they are forced to see the tree watching them and also being hit in the end. I can also help guide the players with vision blockers and signs to encourage the intended path and mistakes for the game. Lastly, having triggers disconnected from objects, like the tree that disappears, can be a useful tool to allow for some fun behaviors if I want to keep users on their toes.

Challenges

Implementing the trigger script and making sure the settings to activate things properly is correct was a bit of a struggle at first, but after I did it a couple times, it was the same pattern to follow so that wasn't too bad. I'd say figuring out what I wanted the layout of the maze to be and where I wanted other objects was the most challenging part for me. I think in the future it would really help me to draw out a sketch on paper of what I want my environment to look like so I am not randomly placing things on the fly.
