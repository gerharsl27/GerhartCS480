HW 2: Unity Intro Roll-a-Ball

My Unity Scene

Personal Modification

Outside of the things described in the tutorial, I decided to add the ability to jump. This wasn't too difficult to add on to the movement already allowed by the player once I found a good tutorial to follow.

Key Takeaways

The tutorial made the majority of this assignment very easy to follow and understand. I would say the most difficult part was when I accidentally moved the enemyBody child instead of the empty enemy parent game object and was struggling to figure out why the enemy was avoiding the player (I displaced the child from the parent that tracked the player's location so it was always a little bit to the side).

Since this is my first time using unity it was interesting to learn how the game objects connected to actual script through the new script component and then how other components like rigidbody are then used and referenced in the script. And it was also surprising how easy it was to link game objects together by just dragging the object to the variable position in unity not even in the script.

XR Documentary Connection

I think the skills we are building now will really start to come in to play when we get into placing the objects we scan with the residents into the scans of the area and setting it up for events to trigger when the user touches or approaches the objects- like how the tokens disappeared when touched. This can enhance the storytelling in our documentaries by increasing the players immersion in the sense that they aren't just watching but also interacting with the stories we tell.
