Larger Connections

With this toolkit, we are now prepared to have all group members working in Unity with the ability to set up meaningful interactions without having to look at or write any code. So now, the CS students will not be the only ones capable of creating the XR interactive environments. There are some limits however, for instance, there are so many actions we could want to cause in unity and, although the toolkit can be used for probably most of what we want, it can account for everything. So, if there are more actions we want to occur outside of whats available in the toolkit, the ENG students may struggle.

Key Takeaways

It was important to make only the settings visible that we want to be alterable to keep the component in the interface window as straight forward as possible. I'm sure I would understand it more the longer I played with it, but there are so many setting available in the Grab interface that it was a lot to take in when I first saw it, and could be very overwhelming for someone new to unity. However, A good aspect in Grab that was carried over to the toolkit was the readability of the titles of settings so it was mostly self explanatory. I would have liked to add something like how the Grab adds a Rigidbody automatically to the components in toolkit that need it so there is less likely to be complications in getting it to work.

Challenges

It was most difficult to figure out how much detail and in between steps I needed to include to be understandable to someone who has never coded before and has little Unity experience. I unfortunately never had the chance to test my guide with someone else, but that would have likely made figuring out specificity much easier as I could have received direct feedback. I also had some issues figuring out how I wanted to link my events initially, but once I got an idea the rest came pretty quickly.
